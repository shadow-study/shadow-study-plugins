# Shadow Study

Connect your existing Shadow Study account to create practice exams and use completed results
for follow-up practice. The tools connect to the hosted service at https://shadow.study/mcp;
this package contains connection metadata and public visual assets.

An existing Shadow Study account with study access is required. Access may be invited or
complimentary, or provided by a subscription when subscriptions are available. This plugin lets you use
your available study features from a compatible AI host. It does not sell anything, process
payments, start subscriptions or upgrades, or charge an additional plugin fee.

## Use

1. Install the package in a compatible host or connect to Shadow Study through its connector settings.
2. Sign in to Shadow Study and approve the connection. Study access is required to use study tools.
3. Share the material and preferences for a practice exam, then ask to create and save it.
4. Open the returned library link to practice on the website. You can also ask to find your exams
   and use selected completed attempts for follow-up practice.

Completed-result reads require results permission and the account's sharing setting. You can
turn sharing off or revoke a connection in Profile. This release has no embedded exam player.
